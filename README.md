# 🍔 유니버셜 키오스크 (Universal Kiosk)

> **모두를 위한 배리어프리 AI 키오스크 (V2)**
> 팀명: **NO PROBLEM KIOSK** · 시뮬레이션 매장: 햄버거 가게

고령층·장애인·어린이·외국인 등 **정보 취약계층**도 누구나 쉽게 쓸 수 있는
"따뜻한 AI" 키오스크입니다. 기존 하드웨어를 바꾸지 않고 **카메라 + AI 소프트웨어**만으로
사용자의 특성을 알아채어 화면이 **스스로 변신**합니다.

---

## ✨ 5대 핵심 기능

> 대회를 앞두고 기능을 늘리기보다 **가장 안정적으로 동작하는 기능만** 남겨 정리했습니다.

| # | 기능 | 누구를 위해 | 설명 |
|---|------|------------|------|
| 1 | **✋ 비접촉 제스처** | 화면 터치가 어려운 분 · 위생 | 손바닥을 들면 커서가 따라옴(에임) → **집기(핀치)** 또는 **손을 2초 멈추기(드웰)** 로 선택, 손을 좌우로 휘둘러 카테고리 넘기기 |
| 2 | **🤖 나이 인식 자동 화면 전환** | 어린이 · 어르신 | 학습된 CNN이 얼굴로 **어린이·성인·노인**을 분류 → 다수결(최근 20표 중 13표) + 4초 쿨다운으로 **어린이 모드 / 일반 / 실버 모드(글자 1.5배)** 자동 전환 |
| 3 | **🔊 음성 기능** | 시각장애인 · 저시력자 | 손님이 오면 "눈이 불편하신가요?"를 **소리로 묻고**, '네'면 **고대비 화면 + 음성 주문(마이크 자동)** 으로 바로 진입. 말한 주문을 담은 뒤 **담은 메뉴와 합계를 소리로 읽어 줌** |
| 4 | **🌐 다국어** | 외국인 | 한국어 → English → 中文 버튼 전환, **말한 언어로 화면 자동 전환** (음성 인식·주문 분석도 3개 언어) |
| 5 | **👁 고대비 화면** | 저시력자 | 상단 **👁 고대비 모드** 버튼(또는 접근성 안내 '네')으로 검정 배경 + 노랑·흰 글씨(글자 1.35배) |

### 🗑 이번에 정리(삭제)한 기능

| 기능 | 삭제 이유 |
|---|---|
| **얼굴로 단골 손님 인식** | 얼굴 랜드마크 숫자로는 서로 다른 사람도 거의 같게 나와(코사인 0.99 이상) **다른 손님을 단골로 오인식**했고, 개인정보 위험도 커서 코드·DB·테스트에서 **완전히 삭제**했습니다. 예전 DB에 남은 단골 테이블은 시작할 때 자동 삭제됩니다. |
| GPT(LLM) 온라인 주문 분석 | 인터넷·API 키가 필요하고 응답이 늦으면 화면이 멈출 수 있어 제거 → **오프라인 규칙 분석기**만 사용(언제나 같은 결과) |
| 엄지척(👍) = 결제 제스처 | 엄지 인식이 가장 흔들려 **실수로 결제**될 위험 → 결제는 **결제 버튼 위 손 멈춤(드웰)** · 터치 · 음성("결제할게요")으로만 |

## 🧮 교과 융합(STEAM) 요소 (계획서 4장)

- **수학** — 유클리드 거리 `d=√Σ(xᵢ−yᵢ)²`(핀치·손가락 펴짐 판정), 코사인 공식 `(A·B)/(‖A‖‖B‖)`(손가락 관절 각도)
  → [core/mathutils.py](core/mathutils.py), [core/vision.py](core/vision.py)
- **과학** — One-Euro 필터(손떨림 커서 안정화), 히스토그램 평활화(CLAHE, 조명 보정 원리 구현)
  → [core/mathutils.py](core/mathutils.py)
- **AI 코딩** — 연령 분류 CNN(OpenCV DNN), MediaPipe 손 관절 21점, QThread 멀티스레딩, 객체지향(OOP) 모듈 설계
  → [core/age_model.py](core/age_model.py), [core/vision.py](core/vision.py)
- **언어(영어·중국어)** — 한·영·중 화면 번역 사전, 언어별 음성 인식, 3개 언어 주문 문장 분석(수량 어순 차이 처리)
  → [core/i18n.py](core/i18n.py), [core/nlu.py](core/nlu.py)

## 🚀 실행 방법

### 1) 라이브러리 설치
```powershell
pip install -r requirements.txt
```

### 2) 실행
```powershell
.\.venv\Scripts\python.exe main.py
```

> 💡 **카메라가 없어도 됩니다!** 라이브러리가 없거나 웹캠이 없으면 자동으로 **데모 모드**로 켜지고,
> 화면 상단의 **"시연 도구"** 버튼으로 모드 전환·제스처 기능을 모두 시연할 수 있습니다.
> 음성 주문은 인터넷이 없어도 **글자 입력·예시 문장 버튼**으로 시연할 수 있습니다(주문 분석은 오프라인).

### 3) 자동 테스트
```powershell
.\.venv\Scripts\python.exe tests\test_kiosk.py      # 핵심 계산 9개
.\.venv\Scripts\python.exe tests\test_full.py       # 모듈·통합 45개
.\.venv\Scripts\python.exe tests\test_scenarios.py  # 사용자 시나리오 44개
```

## 🎛️ 시연 가이드 (대회 발표용)

> ⚠️ **연령 자동 인식을 먼저** 보여 주세요. 시연 도구의 모드 버튼(👦🧑👵👁)이나 헤더의 고대비 버튼을 누르면
> 그 손님(세션) 동안은 **자동 전환이 잠깁니다**(다음 손님이 오면 다시 풀림).

1. **🤖 나이 인식** — 카메라 앞에 서면 어린이·일반·실버 모드로 자동 변신 (카메라가 없으면 시연 도구 👦 🧑 👵)
2. **✋ 제스처** — 손바닥으로 커서 이동 → 메뉴 위에서 **집기** 또는 **2초 멈추기**, 좌우로 휘둘러 카테고리 넘기기 (버튼: 👈 👉 ✊)
3. **🔊 음성** — 접근성 안내에 "네" → 고대비 + 음성 주문 / "불고기버거 세트 하나 주시고 결제할게요"처럼 말하면 담고 소리로 안내
4. **🌐 다국어** — 헤더 **🌐 English / 中文** 버튼, 또는 영어·중국어로 말하기
5. **👁 고대비** — 헤더 **👁 고대비 모드** 버튼으로 켜기/끄기

## 🔐 개인정보 보호 설계

- 얼굴 **원본 이미지는 물론, 얼굴에서 뽑은 어떤 숫자(임베딩)도 저장하지 않습니다.**
- 카메라는 **연령대 추정과 손동작 인식에만** 쓰이고, 그 결과(화면 모드·제스처)만 사용합니다.
- 연령 인식 AI도 **내 컴퓨터에서만(오프라인)** 동작하며, 카메라 영상이 외부로 전송되지 않습니다.
- 마이크 음성 인식(🎙 말하기)은 Google 음성 인식을 쓰므로 **말하는 동안의 음성만** 인터넷으로 전송됩니다.
  글자 입력·예시 문장으로 주문하면 아무것도 전송되지 않고, 주문 분석은 항상 내 컴퓨터에서 합니다.
- SQLite 에는 **익명 주문 통계**만 저장되며, 모든 데이터는 **로컬(내 컴퓨터)** 에만 남습니다.
