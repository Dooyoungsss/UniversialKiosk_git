# 🍔 유니버셜 키오스크 (Universal Kiosk)

> **모두를 위한 배리어프리 AI 키오스크 (V2)**
> 팀명: **NO PROBLEM KIOSK** · 시뮬레이션 매장: 햄버거 가게

고령층·장애인·어린이·외국인 등 **정보 취약계층**도 누구나 쉽게 쓸 수 있는
"따뜻한 AI" 키오스크입니다. 기존 하드웨어를 바꾸지 않고 **카메라 + AI 소프트웨어**만으로
사용자의 특성을 알아채어 화면이 **스스로 변신**합니다.

---

## ✨ 4가지 핵심 기능 (계획서 2장)

| # | 기능 | 설명 |
|---|------|------|
| 1 | **비전 AI 연령 맞춤 UI** | 학습된 CNN(OpenCV DNN)이 얼굴을 보고 **연령대(어린이·성인·노인)** 를 분류해 화면이 자동 변신 — 노인에게는 **글자 1.5배 실버 모드**, 어린이에게는 **어린이 모드** |
| 2 | **익명 단골 빠른 주문** | 얼굴 **사진은 저장 안 함**. 눈·코·입의 **숫자 배열(임베딩)** 만 저장해 단골로 등록하고, "늘 드시던 걸로" 원클릭 재주문 |
| 3 | **비접촉 제스처 · 수어 인식** | 손을 좌우로 휘둘러 메뉴 넘기기(스와이프), 주먹으로 담기, 간단 수어 인식 |
| 4 | **LLM 자연어 · 다국어 주문** | "불고기버거 세트 하나, 콜라는 라지로 바꿔주세요" 같은 문장을 알아듣고 장바구니 자동 구성. 영어로 말하면 **UI 전체가 영어로 전환** |

---

## 🧮 교과 융합(STEAM) 요소 (계획서 4장)

- **수학** — 유클리디안 거리 `d=√Σ(xᵢ−yᵢ)²`, 코사인 유사도 `(A·B)/(‖A‖‖B‖)`
  → [core/mathutils.py](core/mathutils.py)
- **과학** — 히스토그램 평활화(조명/역광 보정), 이동 평균 필터(손떨림 제거)
  → [core/mathutils.py](core/mathutils.py), [core/vision.py](core/vision.py)
- **AI 코딩** — QThread 멀티스레딩, 객체지향(OOP) 모듈 설계
  → [core/vision.py](core/vision.py)
- **영어** — GPT 프롬프트 엔지니어링(영문 System Role + Few-shot)
  → [core/nlu.py](core/nlu.py)

## 🚀 실행 방법

### 1) 라이브러리 설치
```powershell
pip install -r requirements.txt
```

### 2) 실행
```powershell
.\.venv\Scripts\python.exe main.py
```

> 💡 **카메라가 없어도 됩니다!** 라이브러리가 없거나 웹캠이 없으면 자동으로 **데모 모드**로 켜지고,
> 화면 상단의 **"시연 도구"** 버튼으로 모드 전환·제스처·단골 기능을 모두 시연할 수 있습니다.

### 3) (선택) GPT 자연어 분석 켜기
```powershell
$env:OPENAI_API_KEY = "당신의_키"
.\.venv\Scripts\python.exe main.py
```
키가 없어도 **자체 오프라인 분석기**로 자연어 주문이 동작합니다.

## 🎛️ 시연 가이드 (대회 발표용)

상단 **시연 도구** 막대 버튼으로 카메라 없이 모든 기능을 보여줄 수 있습니다.

1. **👵 실버 / 👦 어린이 / 👁 고대비** 버튼 → 화면이 즉시 변신 (기능 1)
2. **🙋 단골 시뮬레이션** → 단골 환영 + 늘 먹던 메뉴 원클릭 (기능 2)
3. **👈 👉 ✊** → 제스처로 카테고리 넘기기 / 담기 (기능 3)
4. **🎤 음성으로 주문** → 예시 문장 클릭 후 분석 (기능 4)
5. **🌐 English** → 다국어 전환

```
UniversialKiosk/
├─ main.py                  # 실행 진입점
├─ config.py                # 전역 설정(임계값·경로)
├─ requirements.txt
├─ data/                    # 로컬 데이터: 단골 DB + 연령 AI 모델(data/models/)
├─ core/                    # 백엔드 · AI · 데이터 (OOP 모듈)
│  ├─ menu_data.py          #   햄버거 메뉴 데이터
│  ├─ mathutils.py          #   ⭐ STEAM 수학·과학 공식 구현
│  ├─ vision.py             #   ⭐ 비전 AI (QThread, 얼굴/손/제스처)
│  ├─ age_model.py          #   ⭐ 연령대 분류 AI (어린이/성인/노인, OpenCV DNN)
│  ├─ nlu.py                #   ⭐ 자연어 주문 (LLM + 오프라인 룰)
│  ├─ regulars.py           #   익명 단골 매칭(코사인 유사도)
│  ├─ database.py           #   SQLite3 단골/통계 DB
│  ├─ order.py              #   장바구니 / 주문 세션
│  ├─ speech.py             #   음성 안내(TTS)
│  └─ i18n.py               #   다국어 텍스트
└─ ui/                      # 프론트엔드 (PyQt6)
   ├─ main_window.py        #   ⭐ 메인 화면 + 상태 머신
   ├─ widgets.py            #   메뉴 카드·장바구니·커서·토스트
   ├─ voice_dialog.py       #   음성 주문 입력창
   └─ theme.py              #   4가지 모드 테마
```

## 🔐 개인정보 보호 설계

- 얼굴 **원본 이미지는 절대 저장하지 않습니다.**
- 랜드마크에서 뽑은 **익명 숫자 배열**만 SQLite 에 저장 → 사람이 알아볼 수 없습니다.
- 연령 인식 AI도 **내 컴퓨터에서만(오프라인)** 동작하며, 카메라 영상이 외부로 전송되지 않습니다.
- 모든 데이터는 **로컬(내 컴퓨터)** 에만 저장되어 외부로 나가지 않습니다.
