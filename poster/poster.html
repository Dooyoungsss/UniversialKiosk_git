03시스템 구조 무거운 카메라 분석은 별도 스레드에서, 화면은 멈추지 않게

04핵심 알고리즘 "흔들리는 AI 결과"를 믿을 수 있게 만드는 방법

🧠나이 인식 + 다수결

  1. 얼굴 영역을 위아래·양옆 20% 넉넉하게 잘라냄
  2. 227×227 크기로 바꿔 학습된 CNN에 입력
  3. 8개 나이 구간 → 어린이(0~12) · 성인(15~43) · 노인(48~)
  4. 투표함에 쌓아 20번 중 13번 이상일 때만 결정
  5. 바꾼 뒤 4초 쿨다운 → 화면 깜빡임 방지
3프레임마다 1번 추론모델 없으면 얼굴 비율로 대체

✋제스처 4중 안전장치

  1. 손가락 펴짐 = 거리 비율 + 관절 각도(곧으면 ≈180°)
  2. 히스테리시스: 펴짐 1.15↑ · 접힘 0.90↓, 그 사이는 이전 상태 유지 → 경계 떨림 제거
  3. 최근 6프레임 다수결로 손 모양 확정
  4. 손 크기로 나눠 거리 무관 · 핀치 = 엄지–검지 거리 ÷ 손 크기 < 0.35
  5. One-Euro 필터 + 프레임당 이동 제한 → 커서 떨림·순간이동 제거
드웰 2초(진행 링)담기 0.5초 · 넘기기 0.8초 간격

🎤음성 주문 분석

  1. 마이크 → 글자(STT) → 언어 감지(한글·한자·영어)
  2. 메뉴 키워드(한·영·중) + 수량 어순(한국어는 뒤, 영어·중국어는 앞)
  3. '세트'의 '세'≠3, '한우'의 '한'≠1 → 숫자 오인 방지
  4. 담은 결과를 소리로 읽어 줌
🗣 "불고기버거 세트 하나 주시는데 음료는 콜라 라지로 바꿀게요"
▼ 규칙 분석 (인터넷 없이, 항상 같은 결과)
🛒 불고기버거 세트 × 1 (콜라 L) = 8,700원
5,500 + 세트 2,700 + 라지 500 · 이중 청구 없이 한 줄로
